#### 🔨 What I'm working on

**IK Start analytics dashboard** · *internship project, 2026*
A web dashboard for IK Start's football academy (U14–U19), built in a team of three.
- Imports training data from **PlayerMaker** and **Catapult** and compares players
  against elite benchmarks
- **Video/audio sync tool**: coaches upload a training video plus their mic
  recordings, and the system finds the clap automatically (GCC-PHAT
  cross-correlation) and returns one synced video per coach
- Now piloting **player tracking** from stadium footage with YOLO and CVAT

`Node.js` `Express` `PostgreSQL` `ffmpeg` `Python`
→ Project site and logbook: [fahrtingit.github.io](https://fahrtingit.github.io)
